# Windows TUN / 透明代理客户使用说明（发布版模板）

> 状态：面向后续正式发布的用户说明草案。WFP UDP 透明转发尚未通过 Windows 10 x64 实机端到端验证；在发布门槛解除前，不得将本说明理解为 UDP/WFP 功能已经开放。

## 1. 客户需要准备什么

- Windows 10 x64（正式支持范围以实际发布说明为准）。
- 可正常连接的 Xray 或 Hysteria2 节点配置。
- 具有本机管理员权限的 Windows 账户。首次安装网络驱动/系统服务或启用需要提权的网络功能时，Windows 可能显示 UAC 确认。
- 从官方发布渠道下载的完整安装包。不要从开发 CI 下载未签名驱动，也不要自行复制 .sys 文件到系统目录。

## 2. 日常使用：尽量只需三步

1. 启动 Hurious，导入或选择节点，先确认普通代理连接成功。
2. 打开「设置 → 网络 / TUN」（最终菜单名称以正式版本 UI 为准），开启 TUN 模式。
3. 等待状态显示「TUN 已启动 / 流量接管正常」，再正常打开浏览器、即时通讯或其他应用。

如果启用时需要管理员授权，请确认发布者和程序来源后再允许。客户不需要自行填写 WFP 端口、编辑驱动参数或手动创建过滤器。

## 3. 模式和流量范围

- **系统代理**：仅遵循系统代理设置的应用通常会走代理；不遵循系统代理的程序可能不受影响。
- **TUN 全局模式**：系统路由将符合接管范围的 IP 流量送入 TUN。它不代表每个数据包都必然经过远端代理；路由规则仍可选择代理或直连，代理核心自身的连接必须排除以避免回环。
- **应用分流**：正式开放后，用户可按应用设置「代理」或「直连」。优先级、默认策略和冲突处理应以界面说明为准。
- **IPv4 / IPv6、TCP / UDP、DNS**：不同协议族和传输类型必须分别完成验证。未在发布说明中明确标注支持的流量，不应假定已被透明接管。

## 4. 推荐的普通用户配置

- 初次使用保持默认路由策略，不要同时叠加多个第三方 TUN/VPN/透明代理工具。
- 先验证一个常用网站，再验证 DNS、IPv4 和 IPv6；需要 UDP 的应用（例如语音、游戏、QUIC）应单独测试。
- 如需排除局域网打印机、NAS 或公司内网，使用应用提供的直连/绕过规则，不要手动修改系统路由表。
- 不确定某条规则时，先使用默认策略；避免把 Hurious 自身、代理核心或本地中继进程加入强制代理规则。

## 5. 关闭、断网和故障恢复

- 正常关闭：先在 Hurious 中关闭 TUN，再退出应用。不要直接结束服务/驱动进程。
- 连接失败：关闭 TUN，确认系统网络恢复，再检查节点连接、权限提示和应用日志。
- 网络切换或睡眠唤醒后异常：先关闭再重新开启 TUN；若仍异常，导出诊断日志并反馈，不要手动删除 WFP provider/filter 或驱动文件。
- 卸载：使用 Windows「已安装的应用」中的官方卸载程序。卸载流程应负责停止服务、移除本产品过滤器/驱动并恢复网络状态。
- 安全原则：明确选择「强制代理」的流量若无法建立代理链路，不应静默降级为直连；界面必须显示失败原因和恢复操作。

## 6. 客户常见问题

### 开启 TUN 后是否所有流量都会经过代理？

不一定。TUN 负责接收系统路由送入的流量，之后仍由路由规则决定代理、直连或拒绝。代理核心和本地中继必须排除，避免代理流量再次进入自身形成循环。

### 是否会增加流量消耗？

TUN 本身不会凭空复制流量，但被代理的应用数据会通过代理服务器传输，可能产生额外协议开销；具体计费取决于代理服务商和所选路由。直连流量通常不会经过远端代理服务器。

### 是否需要客户手动安装 WFP 驱动？

正式产品应由签名安装包自动安装、升级和卸载所需组件，并在需要时请求管理员授权。客户不应从开发构建产物手动安装驱动。

### 为什么某些 UDP 应用暂时不能保证可用？

UDP 透明转发需要完整的关联建立、回程注入、IPv4/IPv6 和异常清理验证。只有正式发布说明明确宣布支持后，才能将其用于游戏、语音或其他 UDP 业务。

## 7. 正式开放前的发布门槛（内部）

以下项目全部完成并留有可复现记录后，才可将对应功能标记为正式支持：

- Windows 10 x64 上驱动签名、安装、启动、卸载和失败回滚通过。
- WFP 服务权限、BFE 不可用、服务崩溃、进程重启和 PID 复用恢复测试通过。
- TCP 与 UDP 分别完成 IPv4/IPv6 的请求和响应回程验证。
- DNS、QUIC、网络切换、睡眠唤醒、局域网直连和代理进程排除验证通过。
- 断网/服务停止时不存在残留过滤器、流量黑洞或意外直连。
- 发布包只提供一个普通客户可直接安装使用的正式版本；不向客户暴露未签名驱动或开发测试包。
- 用户界面提供明确状态、错误原因、日志导出和一键恢复路径。

在上述门槛全部满足前，UDP WFP 生产开关必须保持关闭；CI 编译成功或模拟测试通过不能替代 Windows 10 实机验证。
